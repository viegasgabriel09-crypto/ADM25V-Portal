# Portal ADM25V

Projeto estático pronto para colocar no GitHub Pages, Netlify ou outro serviço de hospedagem estática.

## Arquivos
- index.html
- style.css
- script.js

## Importante
Esta versão salva os PDFs no navegador usando localStorage. Portanto, os arquivos adicionados ficam disponíveis naquele navegador/dispositivo, não para todos os alunos. Para uma versão realmente compartilhada entre toda a turma, será necessário conectar o portal a um banco de dados e armazenamento online.

## Como publicar
Envie os 3 arquivos para o repositório do GitHub e abra o index.html pela hospedagem configurada.
